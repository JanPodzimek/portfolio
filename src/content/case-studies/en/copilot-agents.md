---
title: AI agents for test analysis
summary: Custom GitHub Copilot agents that help the team with test analysis, test design and documentation.
order: 3
stack: [GitHub Copilot, Custom agents, Prompt engineering]
problem: >-
  Test analyses, test scenarios and application documentation take a lot of time, and their
  quality depends on who writes them and how much time they have.
approach:
  - Designed three specialised agents, a test analyst, a test designer and a documentation writer.
  - Gave each agent its own instructions, scope and output format.
  - Every output is reviewed by a tester before it is used.
result:
  - Faster first drafts of test analyses, test scenarios and documentation.
  - A more consistent structure across the team's analyses.
---
